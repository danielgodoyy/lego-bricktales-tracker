# LEGO Bricktales Tracker - Contexto e Skills
## Objetivo
Desenvolver um "Save Parser"/Mapeador de avanço web para ler arquivos .dat do jogo LEGO Bricktales e extrair dados de progresso (100% completion) focando nos biomas e colecionáveis.

Regras Técnicas (Skills do Agente)
Stack Restrita: HTML, CSS, JavaScript Puro (Vanilla JS). É estritamente proibido o uso de frameworks frontend (como React ou Vue) nesta fase.

Processamento: 100% Client-side usando a File API do JavaScript.

## Design System: 
Interface moderna, responsiva, com Light e Dark Mode, estruturada em "Cards" para cada mundo do jogo. 
A interface deve ter cabeçalho com, no lado superior direito, um botao para mudar para dark ou liht mode seguido de um botao em destaque escrito "upload save" que abrirá um popup para colocar o save (abrindo o explorador de arquivos ou o arrastando)

Versionamento: Faça commits semânticos, lógicos e atômicos no Git após implementar funcionalidades-chave.
